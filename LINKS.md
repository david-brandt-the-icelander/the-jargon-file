# Links

What this edition does with each of the 141 outside links in the File (48 live, 11 moved, 77 archived, 3 dead, 1 unchecked, 1 drop-paragraph). Written by `npm run build` from `data/links.json`, which `npm run links:check` fills in; last checked 2026-11-21. Raymond's text is never changed: only where a link points. Links marked "(by hand)" are a person's decision, recorded in `data/links.json` with `"manual": true`.

Cross-references between entries are checked by every build and every one resolves. They match catb.org's own HTML edition (`data/catb-crossrefs.json`) except in three entries, where catb.org's build missed two links (`CNK` → `splork-`, `splork-` → `CNK`, headwords with `>` and `!` in them) and had one the XML doesn't (`spod` → `geek`).
